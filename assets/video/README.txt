Video di bagian "Kerja" memakai file: assets/video/portfolio.mp.mp4
(rekaman vertikal 9:16, diputar otomatis tanpa suara saat terlihat di layar).

Ingin mengganti video?
1. Taruh file baru di folder ini (format MP4, H.264, sebaiknya vertikal 9:16, < 5 MB).
2. Ubah atribut src pada <video class="reel__video"> di index.html.
3. Ganti juga poster (gambar sebelum video jalan) di assets/img/opt/video-poster.webp.
